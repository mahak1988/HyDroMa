# HyDroMa

> مخزن اصلی پروژه **HyDroMa**

## درباره پروژه

پروژه HyDroMa در مرحله آماده‌سازی است؛ توضیح کامل اهداف و اجزای پروژه به‌زودی در این بخش قرار می‌گیرد.

## ساختار مخزن

| مسیر | کاربرد |
| --- | --- |
| `src/` | کد اصلی پروژه |
| `docs/` | مستندات و راهنماها |
| `data/` | داده‌های ورودی/خروجی |
| `tests/` | تست‌ها و کدهای آزمایشی |

## شاخه‌ها (Branches)

| شاخه | کاربرد |
| --- | --- |
| `main` | نسخه پایدار — فقط کد تست‌شده و آماده |
| `develop` | شاخه توسعه — محل ادغام تغییرات روزمره |

روند پیشنهادی کار:

1. هر تغییر جدید در شاخه‌ای جداگانه از `develop` ساخته می‌شود (مثلاً `feature/my-change`).
2. پس از اتمام کار، تغییرات با یک Pull Request به `develop` ادغام می‌شود.
3. هر زمان که `develop` پایدار شد، با یک Pull Request به `main` منتقل می‌شود.

## شروع کار

```bash
git clone https://github.com/mahak1988/HyDroMa.git
cd HyDroMa
```
