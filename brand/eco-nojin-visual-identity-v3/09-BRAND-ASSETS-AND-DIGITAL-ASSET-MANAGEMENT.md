# 1. هدف سند

این سند استاندارد مدیریت دارایی‌های بصری اکوسیستم Eco Nojin را تعریف می‌کند.

دارایی بصری (Brand Asset) هر فایل یا منبعی است که در شکل‌گیری، نمایش یا اجرای هویت بصری برند استفاده می‌شود.

دامنه این سند شامل موارد زیر است:

- لوگوتایپ‌ها
- فونت‌ها
- تصاویر
- آیکون‌ها
- تصاویر و نمودارهای علمی
- نقشه‌ها
- تصاویر سه‌بعدی
- انیمیشن‌ها
- فایل‌های گرافیکی
- الگوهای اسناد
- دارایی‌های شبکه‌های اجتماعی
- فایل‌های مورد استفاده در رابط کاربری

هدف، ایجاد یک مخزن منظم، قابل ردیابی و قابل نگهداری است تا از تکثیر فایل‌ها، استفاده از نسخه‌های اشتباه، نقض مجوزها و افت کیفیت بصری جلوگیری شود.

**وضعیت:** این سند پیشنهادی است و هنوز مجوز ایجاد ساختار اجرایی یا انتقال فایل‌های موجود را صادر نمی‌کند.

# 2. اصول مدیریت دارایی

## 2.1 Single Source of Truth

برای هر دارایی باید یک نسخه مرجع مشخص وجود داشته باشد.

نسخه‌های مختلف نباید به‌صورت پراکنده و بدون ارتباط با نسخه اصلی نگهداری شوند.

## 2.2 Traceability

هر دارایی باید قابلیت ردیابی داشته باشد:

- شناسه
- نام
- نوع
- برند مرتبط
- نسخه
- منبع
- مالک
- مجوز
- تاریخ ایجاد
- وضعیت تأیید

## 2.3 Reusability

دارایی‌ها باید تا حد امکان قابل استفاده مجدد باشند.

اما استفاده مجدد نباید به کاهش تمایز سه برند منجر شود.

## 2.4 Legal Compliance

هیچ دارایی فاقد وضعیت حقوقی روشن نباید وارد نسخه انتشار شود.

## 2.5 Quality Preservation

تغییر اندازه، فشرده‌سازی، تبدیل فرمت یا ویرایش دارایی نباید کیفیت آن را به‌صورت غیرقابل قبول کاهش دهد.

## 2.6 Version Integrity

نسخه‌های تأییدنشده نباید جایگزین نسخه‌های مصوب شوند.

برای هر برند باید نسخه‌های لازم، متناسب با کاربرد واقعی، تولید شوند.

### Eco Nojin

- لوگوتایپ لاتین

### HyDroMA

- لوگوتایپ فارسی
- لوگوتایپ لاتین
- نسخه ترکیبی
- نسخه افقی
- نسخه مناسب محیط علمی و نرم‌افزاری

### Nojin Marketplace

- لوگوتایپ فارسی
- لوگوتایپ لاتین
- نسخه ترکیبی
- نسخه افقی
- نسخه مناسب محیط فروشگاهی

## 4.2 فرمت‌های مرجع

| فرمت | کاربرد |
|---|---|
| SVG | وب و رابط کاربری |
| PDF | اسناد و چاپ |
| EPS | کاربردهای چاپی و حرفه‌ای |
| PNG | نمایشگرها و کاربردهای سازگار |
| WebP | در صورت نیاز برای پیش‌نمایش |

## 4.3 قواعد

- فایل برداری باید نسخه مرجع باشد.
- نسخه Raster نباید جایگزین نسخه اصلی شود.
- لوگوتایپ نباید بدون حفظ نسبت‌ها تغییر اندازه داده شود.
- رنگ لوگوتایپ باید از نسخه مصوب هویت بصری پیروی کند.
- استفاده از افکت‌های غیرمصوب مجاز نیست.
- لوگوتایپ تایپوگرافیک نباید بدون مجوز به نماد تصویری تبدیل شود.

- Fallback Font تعریف شود.
- عملکرد فونت در مرورگرهای مختلف بررسی شود.

## 5.5 وضعیت

تا زمان تأیید مالک، هیچ فونتی به‌عنوان فونت نهایی برند ثبت نمی‌شود.

`brand-category-description-variant-version.ext`

```text

hydroma-icon-water-v1.svg
marketplace-product-card-placeholder-v1.webp

```

## 13.1 قواعد نام‌گذاری
