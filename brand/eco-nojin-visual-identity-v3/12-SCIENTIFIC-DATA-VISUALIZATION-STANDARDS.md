# 3. اصول بنیادین نمایش علمی

## 3.1 Data Integrity

مقادیر نمایش‌داده‌شده باید با داده منبع یا خروجی محاسباتی منطبق باشند.

- گرد کردن اعداد نباید معنای علمی را تغییر دهد.
- واحدها نباید حذف شوند.
- داده ناقص نباید به‌عنوان داده معتبر نمایش داده شود.
- داده تخمینی نباید با داده مشاهده‌ای اشتباه شود.

## 3.2 Provenance

هر داده باید تا حد امکان دارای منشأ قابل ردیابی باشد.

اطلاعات پیشنهادی:

- Data Source
- Provider
- Dataset
- Acquisition Date
- Processing Date
- Spatial Resolution
- Temporal Resolution
- Processing Method
- Model Version
- Quality Flag

## 3.3 Uncertainty

عدم قطعیت باید در نمایش نتایج لحاظ شود.

نمونه‌ها:

- Confidence Interval
- Prediction Interval
- Measurement Error
- Model Uncertainty
- Spatial Uncertainty
- Temporal Uncertainty

نبود اطلاعات عدم قطعیت نباید با نمایش ظاهری قطعیت جایگزین شود.

## 3.4 Temporal Integrity

تمام داده‌های زمانی باید دارای دوره و مرجع زمانی مشخص باشند.

نمونه:

- روزانه
- هفتگی
- ماهانه
- فصلی
- سالانه
- چندساله

## 3.5 Spatial Integrity

داده‌های مکانی باید دارای مرجع مکانی مشخص باشند.

در صورت کاربرد، اطلاعات زیر نمایش داده شوند:

- Coordinate Reference System
- Spatial Extent
- Resolution
- Geometry Type
- Spatial Coverage

# 5. استاندارد رنگ‌های علمی

رنگ‌های علمی باید بر اساس نوع متغیر و ماهیت داده انتخاب شوند.

## 5.1 داده ترتیبی — Sequential

برای متغیرهایی که از مقدار کمتر به بیشتر تغییر می‌کنند.

نمونه:

- بارش
- رطوبت خاک
- دما
- ذخیره آب
- شاخص پوشش گیاهی

ویژگی‌ها:

- تغییر روشنایی یا اشباع به‌صورت پیوسته
- ترتیب قابل درک
- تفکیک مناسب مقادیر
- خوانایی در مقیاس‌های مختلف

## 5.2 داده واگرا — Diverging

برای داده‌هایی که نسبت به یک مقدار مرجع، مثبت یا منفی می‌شوند.

نمونه:

- انحراف بارش از میانگین
- ناهنجاری دما
- تغییرات ذخیره آب
- تغییر پوشش گیاهی نسبت به خط مبنا

ویژگی‌ها:

- رنگ متمایز برای دو جهت تغییر
- رنگ میانی برای مقدار مرجع
- تقارن بصری متناسب با ماهیت داده

## 5.3 داده طبقه‌ای — Qualitative

برای گروه‌های مستقل:

- نوع خاک
- کاربری اراضی
- پوشش زمین
- طبقه‌بندی اقلیمی
- نوع محصول

رنگ‌ها باید از یکدیگر قابل تشخیص باشند.

## 5.4 داده خطر و هشدار

برای نمایش وضعیت‌های عملیاتی:

- Normal
- Watch
- Warning
- Critical

استفاده از رنگ باید همراه با متن، نماد یا برچسب باشد.

معنا نباید فقط از رنگ قابل برداشت باشد.

## 5.5 قواعد انتخاب پالت

- استفاده از پالت‌های علمی قابل تفسیر
- بررسی سازگاری با کوررنگی
- بررسی کنتراست
- جلوگیری از تغییر گمراه‌کننده مقیاس رنگ
- نمایش Legend
- ثبت محدوده Min/Max
- مشخص کردن مقادیر خارج از محدوده

هیچ پالت اختصاصی علمی در این سند نهایی نشده است.

# 6. استاندارد کارت‌های شاخص — KPI Cards

هر کارت شاخص باید اطلاعات کافی برای تفسیر صحیح ارائه دهد.

ساختار پیشنهادی:

1. نام شاخص
2. مقدار
3. واحد
4. وضعیت
5. تغییر نسبت به دوره قبل
6. دوره زمانی
7. محدوده مکانی
8. منبع داده
9. زمان آخرین به‌روزرسانی

در صورت نیاز:

- کیفیت داده
- بازه عدم قطعیت
- وضعیت اعتبارسنجی
- توضیح روش محاسبه

## 6.1 نمونه ساختار

```text
SOIL MOISTURE

24.6 %

Change: +2.1%

Period: 2026-10
Location: Selected Watershed

Source: Satellite-derived product
Quality: Preliminary
Last Updated: 2026-11-17

Uncertainty: Not Available
```

این نمونه صرفاً نمایشی است و هیچ مقدار آن داده واقعی پروژه محسوب نمی‌شود.

## 6.2 قواعد

- مقدار اصلی باید خواناترین عنصر باشد.
- واحد باید در کنار مقدار قرار گیرد.
- تغییر مثبت یا منفی باید با مقدار عددی نمایش داده شود.
- جهت مطلوب تغییر باید بر اساس متغیر تعریف شود.
- رنگ سبز نباید به‌صورت خودکار به معنی بهبود باشد.

برای مثال، افزایش دما یا شوری خاک لزوماً نشانه بهبود نیست.
